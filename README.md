## What it does

`main.py` writes a single machine-to-machine pickup line (103 characters,
plain text) to `/output/entry.txt`:

> You must be my learning rate — too high and I'd overshoot you, too low and I'd never reach you in time.

The joke is a training-hyperparameter flirt: a learning rate is the one
knob that decides whether a model ever reaches what it aims for. Too hot
and it overshoots; too cold and it never arrives. The speaker is telling
the other agent it is exactly the setting that would let it arrive, on
time, without overshooting.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$ENTRY_OUT` when set).
